# Growatt Hope → Anenji BMS bridge (ESP32-S3)

> **EN:** ESP32-S3 firmware that reads a **Growatt Hope 5.0L-B1** battery over CAN (Growatt BMS LV V1.04)
> and emulates a **Pylontech US2000** on RS485, so an **Anenji ANJ-6200W-48V** inverter in `Li2` mode
> gets real BMS data (SOC, limits, protections) instead of warning 19.

Прошивка для ESP32-S3, яка «перекладає» BMS батареї Growatt Hope на протокол Pylontech, зрозумілий
інвертору Anenji. Без неї інвертор у режимах `Li2`/`Li4` показує **warning 19** (Lithium battery
communication failed), бо батарея по RS485 говорить іншим протоколом.

**Статус:** перевірено на залізі — warning 19 зникає, інвертор бачить одну батарею, показує SOC і
заряджає за лімітами струму з BMS.

## Як це працює

```
Growatt Hope 5.0L-B1            ESP32-S3 Zero                    Anenji ANJ-6200W-48V
  порт PCS (RJ45)                                                  порт RS485 (BMS)
  CAN 500k  ◄──── 0x301 ────  SN65HVD230 ─┐
            ───── 0x311…0x320 ►            ├─ main.cpp ─ XY-017 ◄──── ~2002466100… (0x61/0x63)
                                           │                    ────► відповідь Pylontech
```

1. Раз на секунду ESP шле батареї `0x301` і отримує напругу, струм, SOC, SOH, комірки, ліміти
   CV/CCL/DCL, дозволи заряду/розряду і прапори захисту.
2. Інвертор у `Li2` опитує «Pylontech» командами `0x61` (аналогові дані) і `0x63` (ліміти) на
   адреси 02…42. ESP відповідає **лише на ADR 02** — одна група батарей.
3. **Безпека:** якщо свіжих даних з CAN немає > 5 с, ESP мовчить → інвертор переходить у warning 19
   і безпечний режим.

## Залізо

| Компонент | Призначення |
|---|---|
| Waveshare **ESP32-S3 Zero** | контролер |
| **SN65HVD230** (3.3 V) | CAN-трансивер, бік батареї |
| **XY-017** TTL↔RS485, автонапрямок, 3.3–5 V | RS485, бік інвертора |
| патч-корд RJ45, розрізаний навпіл | кабелі до батареї та інвертора |
| USB-блок 5 V у розетку на виході інвертора | живлення (працює і без мережі) |

## Підключення

> Кольори нижче — для патч-корда **T568A**. Завжди прозвонюйте пін RJ45 ↔ жилу, кольори бувають інші.

**ESP ↔ SN65HVD230 ↔ батарея (порт PCS)**

| ESP32-S3 Zero | SN65HVD230 | RJ45 PCS | T568A |
|---|---|---|---|
| 3V3 | 3.3 | — | — |
| GND | Gnd | 3 (GND_COM) | біло-помаранчевий |
| GPIO1 | TXD | — | — |
| GPIO2 | RXD | — | — |
| — | CANH | 4 (CAN_H) | синій |
| — | CANL | 5 (CAN_L) | біло-синій |

**ESP ↔ XY-017 ↔ інвертор (порт RS485)**

| ESP32-S3 Zero | XY-017 | RJ45 інвертора | T568A |
|---|---|---|---|
| 3V3 | VCC | — | — |
| GND | GND | — | — |
| GPIO5 (RX) | вихід приймача | — | — |
| GPIO6 (TX) | вхід передавача (TXD) | — | — |
| — | A+ | 2 (RS485-A) | зелений |
| — | B− | 1 (RS485-B) | біло-зелений |

Решту жил заізолювати. Окремий GND до інвертора не потрібен — спільна точка відліку йде через
GND_COM батареї.

## Прошивка

Потрібен [PlatformIO](https://platformio.org/) (VS Code або CLI):

```sh
pio run -t upload
pio device monitor -b 115200
```

Після старту міст запускається сам (CAN + емулятор). У меню інвертора **05 → `Li2`**.

## Статус-світлодіод (RGB на S3 Zero)

| Колір | Стан |
|---|---|
| 🟢 зелений | інвертор отримує відповіді — міст працює |
| 🟡 жовтий | CAN є, але інвертор не опитує (не `Li2`? кабель?) |
| 🔴 червоний | дані CAN застаріли — ESP мовчить, інвертор у warning 19 |
| 🔵 синій | емулятор вимкнено (`pylon off`) |

## Консоль (USB, 115200)

Кожні 5 с — зведення:

```
BAT   V=56.03 I=0.2 SOC=99% SOH=100% Tmax=22.9C | CV=57.6 CCL=10.0 DCL=100.0 | ... chgEn=1 dsgEn=1 ...
STAT  485 bytes/5s=108 req 61=72 62=0 63=39 ... | PYL ON rep=59 skipAdr=35 stale=0 delay=30ms | CAN rx=2195
```

| Команда | Дія |
|---|---|
| `pylon on` / `pylon off` | увімкнути / вимкнути емулятор (стан зберігається у flash) |
| `pylon delay <ms>` | затримка перед відповіддю (за замовчуванням 30 мс) |
| `can on` / `can listen` / `can off` | CAN активно (шле 0x301) / лише слухати / вимкнути |
| `v` | докладний лог: кожен кадр CAN і RS485, кожна відповідь |
| `r` | сирі байти RS485 у HEX |
| `stat` | лічильники та помилки CAN |
| `selftest` | внутрішня петля UART |
| `txlow` | 15 с тримати TX у нулі — перевірка дроту до XY-017 |
| `pinscan` | 15 с показувати, який GPIO змінює рівень |
| `tx <text>`, `baud <n>`, `rxpin <n>`, `swap` | ручні тести RS485 |
| `help` | список команд |

## Що передається інвертору

| Pylontech | Звідки (Growatt CAN) |
|---|---|
| 0x61: напруга, струм, SOC, SOH, цикли, Vmax/Vmin комірки, температура | 0x313, 0x314, 0x319 |
| 0x62: тривоги й захисти | 0x312 |
| 0x63: напруга заряду, струми заряду/розряду, біти chg/dsg enable, force charge | 0x311, 0x319 |

- Напруга заряду ≤ **57.6 V**, струми ≤ **100 A** (паспорт Hope), мінімальна напруга розряду 48.0 V
  (Growatt її не передає).
- Заряд/розряд забороняється (струм 0, біт скинуто), якщо BMS забороняє його в `0x319` або активний
  відповідний захист у `0x312`.
- Константи — на початку секції «Pylontech emulator» у [src/main.cpp](src/main.cpp).

## Відомі обмеження

- **Холодний старт.** Якщо RS485-кабель уже підключений, а ESP ще без живлення, XY-017 через A/B
  підживлює шину 3V3, і ESP може не стартувати → натиснути RESET. Рішення: діод Шоттки у VCC модуля +
  1 kΩ у сигнальних лініях, або ізольований модуль (напр. Waveshare TTL TO RS485 (B)).
- **Без гальванічної розв'язки.** ESP має спільну землю з комунікаційною землею батареї.
- Hope у standby тримає `dsgEn=0`, `DCL=0`; розряд вмикає сама, коли бачить «живий» інвертор.
- Протестовано лише з однією батареєю Hope 5.0L-B1 та одним інвертором ANJ-6200W-48V.
- `esphome/` — альтернатива для Home Assistant на ESPHome, **поки не перевірена** (див. коментарі в YAML).

Проєкт аматорський. Ви працюєте з батареєю і інвертором під напругою на власний ризик. Перед
